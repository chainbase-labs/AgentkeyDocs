1. Sign in to the [AgentKey console](https://console.agentkey.app). A new
   account starts on the Free plan — no card needed.
2. Open [**API Keys**](https://console.agentkey.app/api-keys), enter a label
   (for example `my-app` — it shows up in your call logs) and click
   **Create key**.
3. Copy the key right away. The full `ak_...` value is shown only once; if you
   lose it, create a new key and revoke the old one.
