The **E-commerce** category lets agents read marketplaces the way a shopper
does: search listings by keyword, open a product page, read its reviews and SKU
options, list what a shop sells, pull best-seller rankings and check what items
actually sold for — across global and Chinese marketplaces, retailers, app
stores and review sites.

## Platforms

Catalog tools in this category come from **JustOneAPI**, named
`JustOneAPI/getApi<Platform><Operation>V<n>` — several platforms expose more
than one version of the same operation — and from **AnyAPI**, named
`AnyAPI/<platform>_<operation>` (for example `AnyAPI/ebay_search`); where both
serve a platform, `find_tools` returns both routes. Global marketplaces are
listed first, then the Chinese ones, then app stores and review sites; each
has its own page, and
[Product research workflows](/capabilities/ecommerce/product-research-workflows-for-ai-agents) shows
how to chain them.

The per-call cost is shown by `describe_tool`. Prices come back in the
platform's own currency, and several marketplaces take a `country` or site
parameter — check `describe_tool` for the exact fields.

<Note>
  **Building with code?** Developers and enterprise integrations can call this
  category through [Scenario Methods](/api-reference/scenario/overview): fixed
  REST contracts with a stable schema, a fixed price and automatic provider
  failover. The methods are listed by platform in the API Reference sidebar.
</Note>

## Browse the catalog

```text
find_tools(prefix="ecommerce")
find_tools(prefix="ecommerce/taobao")         # one marketplace's subtree
find_tools(q="search Amazon for wireless earbuds under 50 dollars")
describe_tool("<returned Provider/Operation>")
execute_tool("<Provider/Operation>", { ...params })   # copy describe_tool's execute_as
```

<Note>
  Marketplaces differ in which fields a product carries and which region or
  site a tool targets — check `describe_tool` for the exact parameters.
  `execute_tool` calls exactly the tool you name; if you want AgentKey to pick
  the route and fail over for you, use a Scenario Method.
</Note>
