The **Search** category gives your agent fresh web results — the live data a
base model can't reach. Six engines sit behind it. Each is a separate
`Provider/Operation` with its own parameters, so discover with `find_tools`,
read the parameters with `describe_tool`, then `execute_tool` the one you chose.

## Providers

| Provider | Operations in the catalog |
| --- | --- |
| **Brave** | Web, news, image and video search; place search and local POI descriptions; LLM-context chunks (`getLlmContext`); suggest, spell check and rich results |
| **Serper** | Google web, news, image, video, maps, places, shopping, patent and scholar search; query autocomplete |
| **Tavily** | Search (`post_search`), plus `post_extract`, `post_crawl` and `post_map` for pulling page content from one URL, a whole site or a site map |
| **Exa** | Web search with a selectable retrieval mode (auto / neural / keyword / fast) and optional page text or highlights per result |
| **Parallel** | Batched web search — several queries in one call |
| **Perplexity** | Web search that returns the relevant page contents |

Tool names follow the engine: `Brave/getWebSearch`, `Serper/searchNews`,
`Tavily/post_search`, `Exa/search`. The per-call cost is shown by
`describe_tool`.

<Note>
  **Building with code?** Developers and enterprise integrations can call this
  category through [Scenario Methods](/api-reference/scenario/overview): fixed
  REST contracts with a stable schema, a fixed price and automatic provider
  failover. The methods are listed by platform in the API Reference sidebar.
</Note>

## Browse the catalog

```text
find_tools(prefix="search")                                      # every search tool
find_tools(q="latest news about Anthropic from the past week")    # ranked by intent
describe_tool("Brave/getNewsSearch")                             # params + per-call cost
execute_tool("Brave/getNewsSearch", { ...params })               # copy describe_tool's execute_as
```

<Note>
  `execute_tool` calls exactly the tool you name — there is no automatic
  failover in the catalog. If an engine is down, pick another from the
  `find_tools` result, or use `web.search`, which fails over for you.
</Note>
