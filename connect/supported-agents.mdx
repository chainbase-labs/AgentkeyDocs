AgentKey works with the agents below, plus any client that speaks MCP. Each card
opens the [console get-started flow](https://console.agentkey.app/get-started),
which detects your OS and gives you the exact command or steps for that agent.

<Tip>
  Not sure which install method applies to you? [Installation](/connect/install)
  explains the methods — the one-line installer, plugin marketplaces, prompt
  install and desktop config — and the get-started flow picks the right one
  for your agent.
</Tip>

## Any other MCP client

Agents that can add a custom MCP server connect with the server URL
`https://api.agentkey.app/v1/mcp`. Clients that support OAuth sign in to
AgentKey in the browser; clients that take a header use
`Authorization: Bearer <your API key>` with a key from the
[console](https://console.agentkey.app/api-keys).
